# Dhrupad Gupta — Portfolio

Personal portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
npm run preview
```

## Editing content

All text (experience, projects, skills, links) lives in `src/data.js`.
Images and `resume.pdf` live in `public/`.

Deploys as a static site (e.g. Vercel: framework preset **Vite**).
